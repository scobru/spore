Spore

Sovereign P2P music and file digging on Freenet. No central servers, no accounts, no algorithm.

Get Spore Features

What it does

🔍 Search

Dense Soulseek-style results: format, bitrate, size, peer, speed. Filter FLAC, MP3, WAV and extras. Double-click to download.

⚡ Transfers

Direct WebRTC between peers. Pause, resume, cancel. Auto-resume when a peer comes back.

📁 Shares

Fast Rust scanner reads tags and BLAKE3-hashes your library. Your manifest is announced on Freenet.

👥 Browse peers

Open a peer's folder tree. Queue a whole album in one click.

📻 Spore Radio

Start a broadcast, share a spore:radio:<roomId> link, friends listen peer-to-peer.

✏️ Tag editor

Edit ID3 and Vorbis tags in place. Hash refreshed on save.

Why Spore

Zero central servers

Catalogs live in Freenet state contracts, not on someone's index server.

Tiny footprint

Tauri v2 and Rust. About 15 MB binary, about 40 MB idle RAM.

Music only

Audio, cover art, booklets, cue and rip logs. Executables are rejected.

Two privacy modes

Direct P2P for speed (pair with a VPN to hide your IP), or freenet-blob sharded storage for anonymity.

Build it

git clone https://github.com/scobru/spore.git
cd spore
npm install
npm run tauri dev

Needs Node 20+, Rust stable, a C++ toolchain and a running Freenet node on 127.0.0.1:7509. See the README for exact steps.
